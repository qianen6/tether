Tether {{VERSION}}

用手机通过加密隧道控制电脑上的编程 agent。电脑上装桌面版（或命令行版），手机上装 Android App，然后在电脑上点"配对"，用手机扫码。

## 下载

| 平台 | 文件 |
|---|---|
| Windows x64 | `Tether_*_x64-setup.exe`（推荐）或 `Tether_*_x64_en-US.msi` |
| macOS Apple 芯片 | `Tether_*_aarch64.dmg` |
| macOS Intel | `Tether_*_x64.dmg` |
| Linux x64 | `Tether_*_amd64.AppImage` 或 `Tether_*_amd64.deb` |
| 命令行版（无界面，适合服务器） | `tether-cli-<平台>.zip` / `.tar.gz`，解压后运行 `tether serve` |
| Android | `tether-android.apk`（如有） |

`SHA256SUMS` 是所有文件的校验值。
